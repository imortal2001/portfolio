03 Problem solving

Hard problems,
simple experiences.

A few of the tricky bits behind the projects above — and how I solved them.

Jammr

Everyone hears the same second

The server never streams audio or a playhead. It stores “position P at server time T”; each client estimates its clock offset with NTP-style pings and corrects any drift over 1.5 s. New songs start 1.5 s in the future so every device can buffer and begin together.

Result: tight sync across browsers and phones with almost no server load.

KusinaLink

Never sell the last plate twice

Stock is deducted at the moment an order is placed, inside a single atomic Postgres function — so two customers racing for the last serving can’t both win. Cancellations return stock, and orders snapshot the name and price they were bought at.

Result: the kitchen’s numbers always match reality.

Isla Lola

A game that grows without breaking saves

All game rules live in a pure, renderer-free state module covered by Vitest suites. Saves are versioned and migrated forward (v1 → v6), so every new season, crop and feature arrived without wiping anyone’s progress.

Result: new seasons ship without resetting anyone’s progress.

Jammr

Unlimited music on a 100-search budget

YouTube allows ~100 searches a day. I built a matching pipeline that tries free sources first — MusicBrainz by ISRC, then the artist’s official channels — and only searches as a last resort, caching every match and pre-matching chart songs on a cron.

Result: most songs never touch the search quota.

KusinaLink

Deploys that really went live

The hosting alias sometimes kept serving the previous build after a production deploy. My deploy script stamps each build with a unique ID, polls the live site for it and re-promotes until the new version is actually being served.

Result: one command, and production is verified fresh.

Isla Lola

Speaking the player’s language

A small i18n layer with English keys ships the UI in English, Filipino, Cebuano, Ilocano and Hiligaynon — with a glossary that deliberately keeps the characters’ Taglish dialogue intact, because that’s how they really talk.

Result: a game that feels local, not translated.
